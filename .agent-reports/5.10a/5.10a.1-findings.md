# Build 5.10a.1 — replayable main-screen load-in

Updated October 9, 2026.

- `ContentLoadIn` is keyed by `LocationViewModel.loadInGeneration`; every new generation snaps each block out without animation and reuses the existing sentence → card → compass stagger.
- A search pick replaces the selected place synchronously before the sheet finishes closing, so the prior place cannot reappear.
- “Use my location” removes the old place as soon as its row is selected and changes the sentence token to “your location” while the fix is pending.
- The generation changes for search picks and explicit detected-place replacements. It does not change for date navigation, a same-city refresh, or an unchanged foreground return.
- A failed or blocked explicit replacement does not restore the old card.

Focused LOADER.md §12.5 tests cover generation routing and the immediate “your location” state. Screenshots and recordings are added with 5.10a.2 after the delayed skeleton is available.
